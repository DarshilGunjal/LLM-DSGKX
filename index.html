The Tokenizer: Byte-Pair Encoding (BPE)

Computers cannot read letters; they process integers. How does English text convert to an array of integers?

Time Complexity: O(N)

• The First-Year Mental Model: The Subword Dictionary

Why not full words? If every word had an ID, the dictionary would need 1,000,000+ IDs (huge GPU memory), and typos like "heyyy" would break. Why not single characters? Sentences would take thousands of steps. BPE is the golden middle: Frequent combinations like "th" and "ing" become single tokens, while rare words are broken into subword pieces!

Stage 03

Positional Encodings: Why Order Matters

Self-attention is completely permutation-invariant. How does the model know word order?

Operation: Element-wise Vector Addition

• The First-Year Mental Model: The Anarchy of Unordered Sets

Without positions, the mathematical dot-product matrix sees:
"Dog bites man"  and  "Man bites dog" as 100% IDENTICAL! Because Self-Attention operates on sets, we must physically inject a unique wave pattern into each token vector based on its index position $pos$.

Vaswani Sinusoidal Positional Formulas:
$$\begin{aligned} PE_{(pos, 2i)} &= \sin\left(\frac{pos}{10000^{2i/d}}\right) \\ PE_{(pos, 2i+1)} &= \cos\left(\frac{pos}{10000^{2i/d}}\right) \end{aligned}$$
Where $pos$ is token sequence index ($0, 1, 2, \dots$), $i$ is vector dimension index, and $d$ is embedding size.

Stage 04 • The Core Engine

Self-Attention Mechanism ($Q, K, V$)

How every word computes context by attending to every other word in the prompt.

Compute Complexity: O(N²)

• The First-Year Mental Model: The Search Engine / Key-Value Database Analogy

Imagine searching a library:
1. Query ($Q$): What you type in the search bar (e.g. pronoun "it" asking "who am I referring to?").
2. Key ($K$): The label or tags on each book in the catalog.
3. Dot Product ($Q \cdot K^T$): Relevance score between your search query and each catalog key.
4. Value ($V$): The actual content inside the matched book extracted with weighted importance!

The Golden Equation (Vaswani et al., 2017):
$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V$$
Why divide by $\sqrt{d_k}$?
For large dimensions $d_k$, dot products grow huge ($Q \cdot K \sim d_k$). Large numbers push the Softmax function into saturated regions with tiny near-zero gradients (the vanishing gradient problem!). Dividing by $\sqrt{d_k}$ stabilizes variance to 1.

Stage 05

Feed-Forward Network (FFN) & Residual Highways

Where factual knowledge is stored and gradients are kept alive across 80+ layers.

+

Residual Skip Connection

$$\mathbf{x}_{\text{out}} = \mathbf{x} + \text{Attention}(\mathbf{x})$$ Directly adds original input to the output. Acts as an uninterrupted highway allowing backpropagation gradients to flow without vanishing.

μ

Layer Normalization (RMSNorm)

$$\text{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d} \sum_{i=1}^d x_i^2 + \epsilon}} \odot \gamma$$ Stabilizes activations across the network so numbers don't explode to $\infty$ or shrink to $0$.

ƒ

MLP / FFN Memory Bank

$$\text{FFN}(x) = \text{GELU}(x W_1 + b_1) W_2 + b_2$$ Expands dimensions $4\times$ ($d \to 4d \to d$). Research shows FFN layers act like associative memory storing world facts!

Final Layer Hidden State → Logits → Softmax
Stage 06 • Probabilistic Generation

Softmax & The Creative Sampling Playground

How the model converts raw scores (logits) into a probability distribution and decides the next token.

Formula: $P(w_i) = \frac{e^{z_i / T}}{\sum e^{z_j / T}}$

• The First-Year Mental Model: Rolling a Weighted 50,000-Sided Die

An LLM never outputs text directly; it outputs a probability distribution over every token in its dictionary!
• Temperature ($T$) controls how peaked or flat the dice probabilities are.
• Top-K restricts rolling to only the top $K$ faces of the die.
• Top-P (Nucleus) dynamically keeps the smallest subset of words that together sum to $P\%$ probability mass.

Temperature ($T$): 0.70
0.1 (Greedy / Argmax) 0.7 (Balanced) 2.0 (Chaotic)
Top-K Cutoff: 5

Only the top $K$ tokens can be sampled. Tokens below are pruned to $0\%$.

Top-P (Nucleus): 0.90

Cut off the long tail once cumulative probability reaches $P$.

Stage 07

Autoregressive Generation Studio

How LLMs write essays one token at a time by feeding their own output back into their input.

KV Cache: 5 vectors cached
• Why Generation Doesn't Slow Down: The KV Cache

In naive generation, predicting the 100th token would re-run attention over all 99 previous tokens from scratch ($O(N^2)$ per step). With a KV Cache, the GPU saves the Key and Value matrices of all prior tokens in high-speed VRAM. The model only computes $Q$ for the single newest token, dropping computation per step to $O(1)$!

From Math to Python: 10 Lines of PyTorch Attention

The exact Python code you will write in your machine learning lab.

import torch
import torch.nn.functional as F

def scaled_dot_product_attention(Q, K, V):
    # Q, K, V have shape: (batch_size, num_heads, seq_len, head_dim)
    d_k = Q.size(-1)
    
    # 1. MatMul Q and K^T: (seq_len x seq_len)
    scores = torch.matmul(Q, K.transpose(-2, -1)) / (d_k ** 0.5)
    
    # 2. Softmax along the last dimension
    attention_weights = F.softmax(scores, dim=-1)
    
    # 3. Weighted sum of Value vectors
    output = torch.matmul(attention_weights, V)
    return output, attention_weights
